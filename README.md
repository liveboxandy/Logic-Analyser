# Logic-Analyser
Cloned and modified from  (https://github.com/gusmanb/logicanalyzer)

1 - Pico can be mounted on headers. Suggest Samtec BBL or SL style.
2 - Uses 0805 rather than 0402 SMT components so I can see and solder them.
3 - Has keepout area for Pico WiFi.
4 - PCB is slightly larger than the orignal.
5 - No ther changes that I can remember
